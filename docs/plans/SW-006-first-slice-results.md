# SW-006 first implementation slice: local Android camera capture

1 October 2026. Implemented by Codex with three isolated agents; reviewed by Codex agents (not independent qualification). Product-owner instruction: start the Android C121 development plan.

## Implemented development behavior

Android local setup offers Camera input. Start camera turn, open Capture/review, configure local camera account in the native sheet, connect, capture calibration image and mark eight inside tray corners. Capture seeks four matching clear frames spanning at least 650ms; incomplete readings remain visibly correctable. Confirm performs fresh scene/context checks, then persists one reviewed roll with a stable command ID. Legal score recommendations use existing pure rules. Score remains a separate action. Confirmed rolls can be corrected/excluded or the turn finished manually. Original prediction, correction, source, logical holds and timing provenance survive in game history/exports and this-game analytics.

Native implementation: Media3 1.11.1 RTSP over TCP on Wi-Fi, configurable stream1/stream2, generation invalidation, connection/render watchdog, explicit manual reconnect, app pause cleanup, native credential entry, Keystore-protected AES-GCM storage and backup exclusions. One pull acquisition and one private PNG lease; no preview-rate base64. Snapshot timing means local render, never sensor capture. The JS bridge maps a conservative age bound into the JS monotonic domain; freshness uses bridge receipt time plus the age bound once. Calibration is retained across reviewed rolls only while the native stream session remains live; background/reconnect requires recalibration. Explicit panel close/disconnect releases native resources; successful roll confirmation hides preview while retaining the current session for scoring/next capture.

Reusable camera frame/session/replay interfaces are implemented and tested with explicit simulated/replay origin. One inference plus latest queued frame; cancellation, stale/session/calibration/context checks and release ownership are covered. Human frozen review is not forced into the old two-second live-frame window. An image-tile change guard covers unreadable scene regions during confirmation; its conservative thresholds require optical validation and are not an accuracy claim.

Hosted camera rooms, continuous pickup-driven capture, approach-side hints and cross-game analytics are subsequent slices. Existing hosted GoDice authority remains unchanged. Current capture is manual-assisted: the player deliberately requests each roll, confirms logical kept slots and reviewed values. A new video frame alone does not prove a physical reroll; automatic physical-roll deduplication/pickup tracking is not qualified.
