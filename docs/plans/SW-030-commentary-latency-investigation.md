## Repair scope

1. Add correlated privacy-safe monotonic spans for endpoint auth, durable load/commit (bytes/retries), writer-ready, poll receive, acquire/claim, native request/first-byte/playout. Keep provider timings separately; do not reset baseline before the accepted score.
2. Replace global snapshot read/modify/write with narrow room/job operations and bounded caption projections. Polling should read; necessary expiry/invalidation updates stay conditional and server-authoritative. Preserve audience, accepted-event/Undo, account/seat, profile, lease/epoch and budget enforcement atomically in SQL.
3. Trigger ready-job delivery promptly from accepted work and avoid repeated background writers on every poll. Reduce network round trips by validating the same guarantees in a narrow atomic backend operation; do not delete authorization checks or broaden grants.
4. Trace native first-byte→playout separately before changing buffering. ElevenLabs Flash is already quick in these samples; switching voice/model or reducing humor quality is not justified by this evidence.
